SDK Li2 là lớp kết nối giữa website của bạn và Li2. Sau khi được cài đặt, SDK cho phép website gửi dữ liệu về Li2 để kích hoạt các **tính năng phân tích** và **đo lường**.

SDK chỉ cần cài **một lần cho mỗi website**.

Sau khi kết nối thành công, bạn có thể tiếp tục bật thêm các tính năng khác mà không cần cài lại.

## SDK Li2 dùng để làm gì?

Phần lớn tính năng trên Li2 cần SDK để hoạt động. Sau khi SDK được cài đặt, bạn có thể sử dụng các tính năng như:

### Phân tích hành vi website

Hiểu cách khách truy cập tương tác với website thông qua dữ liệu như:

- lượt xem trang
- lượt nhấp
- cuộn trang
- biểu mẫu
- phiên truy cập
- hành trình duyệt web

Các dữ liệu này giúp bạn nhìn rõ nơi người dùng tiếp tục, dừng lại hoặc rời khỏi website.

### Conversion Measurement

Đo lường điều gì xảy ra sau khi người dùng nhấp vào link marketing. Ví dụ:

- Đăng ký tài khoản
- thêm sản phẩm vào giỏ hàng
- tạo đơn hàng
- doanh thu phát sinh

Điều này giúp bạn biết **chiến dịch nào đang tạo ra conversion** thực tế.

### Heatmap & Session Replay

Xem khu vực được tương tác nhiều nhất trên ebsite và xem lại trải nghiệm truy cập theo từng phiên.

### Funnel & Customer Journey

Phân tích hành trình chuyển đổi và xác định bước nào đang tạo ra điểm rơi trong funnel.

Tôi có cần cài SDK cho mọi website không?

Có. Nếu muốn sử dụng các tính năng phân tích website hoặc conversion measurement của Li2, bạn cần kết nối website với SDK.

SDK chỉ cần cài một lần cho mỗi website.

Sau khi cài đặt hoàn tất, bạn có thể tiếp tục cấu hình thêm các tính năng khác bất kỳ lúc nào.

## Tôi có thể gỡ SDK sau khi cài không?

Có. Bạn có thể tắt hoặc gỡ SDK bất kỳ lúc nào bằng cách:

- disable plugin
- xoá script
- huỷ cấu hình integration

Sau khi SDK ngừng hoạt động, website sẽ không tiếp tục gửi dữ liệu về Li2.
